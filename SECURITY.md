# Security Policy

## Supported versions

Security fixes are released for the latest minor version of NetBox Rack Design
(currently 1.2.x). See [COMPATIBILITY.md](COMPATIBILITY.md) for the NetBox
versions each release supports.

## Reporting a vulnerability

Please report vulnerabilities privately through a
[GitHub security advisory](https://github.com/ravenrs/netbox-rack-design/security/advisories/new)
rather than a public issue. Include the plugin and NetBox versions, the steps to
reproduce, and the impact you observed.

You can expect an acknowledgement within a few days. Fixes ship as a patch
release, and the advisory is published once the release is on PyPI.

The plugin's permission model is described in [docs/security.md](docs/security.md).
