# netbox-rack-design-mcp

Read-only MCP server (stdio) for the [netbox-rack-design](https://github.com/ravenrs/netbox-rack-design)
NetBox plugin. Set `NETBOX_URL` and `NETBOX_TOKEN`, then run `netbox-rack-design-mcp`.
Setup for Claude Desktop and Claude Code: see `docs/mcp.md` in the plugin repository.
